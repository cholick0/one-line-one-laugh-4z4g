## The line

> My agent read the meeting notes, summarized them in one word: 'pointless' — then billed me for the insight.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt`, then runs a self-check gate: 1–140 characters, exactly one line, non-blank, plus byte-for-byte read-back verification.

```sh
~/workspace/tools/node22/bin/node main.ts
```
